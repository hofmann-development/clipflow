ClipFlow Pro

A lightweight clipboard text manager for Windows.

Save clipboard text Ctrl + Alt + S
Load text into the clipboard Ctrl + Alt + L

Getting started

Start clipflow.exe.

ClipFlow runs quietly in the background. Use the keyboard shortcuts above whenever you want to save or load text .

Save clipboard text

  1. Copy the text you want to save.
  2. Press Ctrl + Alt + S.
  3. Choose a file name and location.
  4. Confirm the save operation.

Load text

  1. Press Ctrl + Alt + L.
  2. Select a text file.
  3. Confirm the file selection.
  4. If the file contains template fields, enter the requested values.
  5. The completed text is placed on the clipboard.
  6. Paste it into another application with Ctrl + V.

Using templates

A template can contain fields that ClipFlow asks you to fill in when the file is loaded.

Single-line field 

$$Name$$

Multiline field 

$$#Message$$

Example 

Dear $$Name$$,

$$#Message$$

Kind regards,
Stefan

ClipFlow asks for the values of Name and Message, replaces the fields, and places the completed text on the clipboard.

Repeated fields

The same field may appear more than once: 

Customer: $$Name$$
Contact:  $$Name$$

ClipFlow asks for the value once and inserts it everywhere the same field appears.

Use the same spelling and capitalization each time.

Literal double dollar signs

To insert double dollar signs without creating a template field, place a backslash before them: 

\$$

The resulting text will contain: 

$$

Cancelling

You can cancel a file selection or template entry at any time. When an operation is cancelled, the clipboard remains unchanged.

Troubleshooting

Windows blocks the application

ClipFlow is not digitally signed. Windows marks the downloaded ZIP archive and may warn about the program or refuse to start it.

Unblock the archive before extracting it: right-click the ZIP file, select Properties, tick Unblock at the bottom of the General tab, and confirm with OK . Otherwise every extracted file keeps the mark.

If the message Windows protected your PC still appears, select More info and then Run anyway.

A hotkey does not work

Another application may already be using the same keyboard shortcut. Close that application or change its shortcut, then restart ClipFlow.

A template field is not replaced

Check that the field begins and ends with two dollar signs. 

$$Name$$

For a multiline field, add a number sign after the opening dollar signs. 

$$#Message$$
